# 城市级信控智能体

基于「感知—认知—决策—执行—评价—进化」六位一体的城市级信控智能体工程框架，对应《城市级信控智能体技术架构设计》与《城市级信控智能体方法论》。

## 架构概览

- **总控层**：城市级信控主智能体，任务拆解、闭环管控、跨模块协同
- **分控层**：五大专业环节子智能体（场景认知、问题诊断、控制策略、方案生成、评价反馈）+ 四大场景管控子智能体（区域/干线/路口/应急）
- **技术支撑层**：大模型能力池、MCP 专业工具集、信控知识库、认知进化引擎、外部工具联动
- **人机协同层**：人工干预、经验沉淀、协同工作流
- **智能体记忆系统**：四层记忆（工作记忆 / 情景日志 / 长期经验 / 语义检索）
- **数据底座层**：多类型数据库、向量存储、数据治理
- **接口与部署层**：REST/gRPC 接口、云原生部署

## 五环节闭环

```
场景认知 → 问题诊断 → 控制策略 → 方案生成 → 评价反馈
    ↑_________________________________________________________|
```

## 项目结构

```
src/
├── master_agent/       # 总控层主智能体
├── sub_agents/         # 分控层子智能体（专业环节 + 场景管控）
├── skills/             # Skill 技能化架构与技能包
├── support/            # 技术支撑层（LLM/MCP/知识库/记忆/进化引擎）
├── data/               # 数据底座抽象与接入
├── human_collab/       # 人机协同层
├── workflow/           # 五环节闭环工作流
└── api/                # 标准化接口与部署入口
```

## 快速开始

```bash
export PYTHONDONTWRITEBYTECODE=1
 .venv/bin/python -m uvicorn src.api.main:app --reload

```

启动后可在浏览器打开 **http://localhost:8000/debug/** 使用调试驾驶舱：健康检查、五环节闭环、诊断→模板（含 **recommend_score** 条形图）、多场景对比（含 **Top 问题等级** 柱状/分布图）、Skill 列表，以及服务端环形缓存的 **历史执行记录**（`GET/DELETE /v1/debug/history`，默认容量可用环境变量 `DEBUG_HISTORY_MAX` 调整）。

**部署落地**：详见 [部署落地指导手册](docs/部署落地指导手册.md)，含本地、Docker、Docker Compose 及生产/云原生部署说明与 API 验证、常见问题排查。
