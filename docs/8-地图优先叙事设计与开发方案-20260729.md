# 城市信控智能体地图优先叙事设计与开发方案

- 文档版本：V1.0
- 形成时间：2026-07-29（Asia/Taipei）
- 适用范围：Act 1、Act 2、Act 6
- 核心原则：地图负责给结论，面板负责给依据

## 1. 改造背景

现有系统已经形成完整、专业的专家研判链，能够依次说明路口认知、方向拆解、异常核验、溢流判因、约束检查、方案生成、反事实推演、专家决策和源头治理。

当前主要问题不是分析内容不足，而是分析结论过度依赖左右分析面板。地图虽然持续存在，但多数阶段承担的是空间背景、对象定位和文字标签承载，尚未通过地图状态变化直接表达：

1. 问题具体发生在哪一段道路；
2. 排队长度如何超过阈值；
3. 上游来车、目标放行和下游承接之间的因果关系；
4. 策略分别落在什么位置、采取什么动作；
5. 不同方案会把交通压力转移到哪里；
6. 执行后问题改善了多少，其他方向是否仍然安全。

领导观看演示时通常先看地图，再根据兴趣查看指标和文字。因此，本轮改造将叙事主角由“智能体完成了九个步骤”调整为“交通状态在城市空间中如何被发现、解释、治理和改善”。

## 2. 总体目标

### 2.1 产品目标

构建一套无需逐字阅读面板，也能通过地图在三秒内理解当前结论的演示系统。

领导仅观察地图时，应能够回答：

- 哪里出现了问题；
- 问题是什么；
- 为什么发生；
- 准备在哪里采取什么动作；
- 方案是否会产生副作用；
- 执行后取得了什么结果。

### 2.2 叙事目标

对外主叙事收敛为五段：

```text
发现
→ 判因
→ 决策
→ 验证
→ 进化
```

现有九步专家研判链继续保留，作为五段主叙事下的专业分析过程和可追溯依据：

| 领导主叙事 | 对应专家研判步骤 |
|---|---|
| 发现 | 路口认知、方向拆解、异常核验 |
| 判因 | 溢流判因、约束检查 |
| 决策 | 方案生成、专家决策 |
| 验证 | 反事实推演、执行效果 |
| 进化 | 源头治理、日报复盘、经验沉淀 |

## 3. 信息分层原则

### 3.1 地图第一层：直接结论

地图必须独立表达当前阶段最重要的一句话，并将数字绑定到实际道路、方向和节点。

### 3.2 面板第二层：证据依据

分析面板用于呈现指标口径、设备来源、现场图像、专家推理、方案参数、护栏条件和审批留痕。

### 3.3 交互第三层：按需详情

悬停、点击或展开后查看设备、车道、单项指标、拓扑节点、案例和过程记录。自动演示不依赖这些内容完成主叙事。

## 4. 地图视觉语法

全流程使用稳定、可学习的地图语义：

| 视觉元素 | 固定含义 |
|---|---|
| 红色 | 已经成立的问题、越界状态 |
| 琥珀橙 | 成因、风险、推演动作 |
| 绿色 | 安全、改善、执行完成 |
| 蓝色 | 正常背景、冲突方向、参考网络 |
| 实线 | 当前真实状态或已执行动作 |
| 虚线 / 半透明 | 阈值、方案状态或预测状态 |
| 流动箭头 | 车流、影响和控制作用传播 |
| 线宽 | 流量、贡献度或影响强度 |
| 道路长度尺 | 排队长度、动态阈值、储车空间 |
| 状态光环 | 目标锁定、执行中、完成 |

每个关键阶段必须同时具备：

1. 地图主结论；
2. 空间证据；
3. 当前状态或下一动作。

## 5. 六个地图主画面

### 5.1 全域发现

地图展示全域扫描覆盖、正常监测路口和唯一异常目标。

目标路口在地图上直接显示：

```text
北进口排队 129m
超过动态阈值 12% · 连续 3 周期增长
```

目标道路段同步高亮，确保不阅读面板也能识别异常方向。

### 5.2 问题成立

镜头进入真实渠化路口，地图直接绘制：

- 从停止线到队尾的 129m 排队长度尺；
- 114.8m 动态阈值线；
- 超过阈值的红色区间；
- 最近三个周期的队尾残影；
- 其他方向的绿色短队列作为对照。

地图主结论：

> 北进口排队连续增长并越过动态阈值，异常成立。

### 5.3 判明原因

地图以动画表达因果链：

- 上游轻风路、工业南路连续来车波；
- 前两跳贡献 57.9%；
- 目标北进口流入强于有效放行，形成瓶颈；
- 下游占有率 42%，剩余储车空间约 168m。

地图主结论：

> 上游连续到达放大排队，目标方向有效放行不足；下游不是病因。

### 5.4 生成策略

三个策略动作必须落在地图具体位置：

- 目标路口：北进口直行相位增加 4 秒；
- 上游节点：来车削峰 12%；
- 下游路段：绿波协调；
- 东西向：保留 92m 排队警戒边界。

地图主结论：

> 采用“适度加放 + 上游削峰 + 下游协调”的走廊协同策略。

### 5.5 反事实推演与决策

在同一张地图上切换三种空间状态：

| 方案 | 北进口 | 东西向 | 下游 | 地图结论 |
|---|---:|---:|---:|---|
| 不干预 | 129m | 63m | 42% | 北进口继续增长 |
| 单点 +8s | 88m | 101m | 61% | 压力转移，东西向越界 |
| 协同组合 | 78m | 71m | 55% | 三处均在安全边界内 |

地图必须通过队列长度、道路颜色和安全边界变化表达方案差异，不能只替换标签文字。

### 5.6 效果与进化

执行完成后，地图展示：

- 北进口排队 129m → 78m；
- 东西向排队 63m → 71m，低于 92m；
- 下游占有率 42% → 55%，低于 65%；
- 目标路口由异常状态转为稳定状态。

随后镜头回到城市范围，展示：

- 今日发现与闭环路口；
- 自动执行、人工确认和待处理分布；
- 已验证策略的可复用范围；
- 新增经验与知识沉淀。

Act 6 不再完全离开地图，而是采用“城市治理地图 + 复盘摘要”的空间收口方式；完整日报作为按需展开的第二层内容。

## 6. 布局调整

### 6.1 自动演示模式

- 地图保持绝对视觉中心；
- 左侧九步链压缩宽度和文字密度；
- 右侧分析面板继续保留，但地图主结论不得依赖其内容；
- 地图中央或下方设置不遮挡道路的“执行摘要条”；
- 关键空间标签字号、数字层级和对比度提升。

### 6.2 详情查看模式

领导点击感兴趣的对象后，再展开：

- 指标详情；
- 视频证据；
- 数据来源；
- 方案表格；
- 护栏条件；
- 人机协同记录。

## 7. 开发方案

### 7.1 地图结论层

在 `CityMap.vue` 增加统一的地图叙事覆盖物：

- `executive-map-verdict`：地图主结论；
- `queue-ruler`：排队长度和阈值；
- `causal-flow`：上游来车和瓶颈；
- `strategy-action`：控制动作；
- `safety-boundary`：安全护栏；
- `outcome-comparison`：执行前后结果。

所有业务对象使用经纬度绑定，高层结论卡使用地图容器内的固定信息层，不使用屏幕百分比绘制道路业务几何。

### 7.2 叙事状态扩展

继续使用现有 beat：

```text
cognition
direction
evidence
cause
constraints
options
simulation
decision
trace
report
```

每个 beat 增加以下地图语义：

```ts
{
  chapter: '发现' | '判因' | '决策' | '验证' | '进化',
  headline: string,
  summary: string,
  tone: 'critical' | 'warning' | 'action' | 'success',
  metrics: Array<{ label: string; value: string }>
}
```

### 7.3 反事实地图状态

`simulation` 阶段自动轮播：

```text
baseline
→ green-only
→ combined
```

地图节点、道路色彩、队列长度和安全状态随方案变化，最终停留在推荐的组合方案。

### 7.4 复盘地图

Act 6 首屏增加城市治理地图摘要，保留日报核心 KPI：

- 闭环完成率；
- 平均响应；
- 今日智能动作；
- 治理效果；
- 经验新增。

完整图表和人机协同工作台继续保留，可从地图摘要进入。

## 8. 验收标准

### 8.1 三秒地图测试

遮住左右面板，仅看地图三秒，测试者能够准确说出当前阶段：

- 目标位置；
- 主要问题或动作；
- 核心结果。

### 8.2 相邻画面差异

方向拆解、成因、方案、推演和决策画面必须有可辨识的地图状态差异，不能只改变小标签。

### 8.3 关键数字上图

以下数字必须直接出现在地图主表达中：

- 129m；
- 114.8m；
- 57.9%；
- +4s；
- 12%；
- 92m；
- 65%；
- 78m；
- 71m；
- 55%。

### 8.4 闭环完整性

演示必须形成：

```text
城市发现异常
→ 路口确认问题
→ 走廊解释原因
→ 多点协同治理
→ 地图验证效果
→ 返回城市持续进化
```

### 8.5 工程质量

- 保持高德地图真实经纬度覆盖物；
- 保持 1920×1080 主适配和 1366×768 可用；
- 通过 TypeScript 编译与生产构建；
- 自动演示、手动跳步和重播均可用；
- 地图加载失败时保留可理解的降级表达。
